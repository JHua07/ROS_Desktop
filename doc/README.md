# Project documents

This folder is the source of truth for the ROS Desktop project plan and design.

Read these files before changing the project:

1. `architecture.md` — runtime shape and module ownership.
2. `versions.md` — selected toolchain versions and verification sources.
3. `specs/` — agreed design requirements and constraints.
4. `plans/` — implementation tasks and acceptance checks.

When a plan or specification changes, update this index if the document set or reading order changes.
